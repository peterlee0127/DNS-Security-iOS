## Version 3.7.0

### Network Exceptions for Pro

- Let selected domains, such as a company intranet, use the network's DNS instead of encrypted DNS.
- Optionally pause encrypted DNS when a URL you choose responds with HTTP 200 after a network change.

Network Exceptions are saved on each device. They are included with DNS Security Pro and available in DNS Security Lite after the Pro in-app upgrade.

The URL is checked when the network changes. A successful manual URL test does not confirm that the system has paused encrypted DNS.
